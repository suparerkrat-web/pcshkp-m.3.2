About Me

รู้จักตัวผม/หนู

ผม/หนูเป็นนักเรียนชั้นมัธยมศึกษาปีที่ 3 ที่มีความสนใจในวิชาคณิตศาสตร์ วิทยาศาสตร์ และการออกแบบสิ่งต่าง ๆ

สิ่งที่ทำให้สนใจวิศวกรรมโยธาคือ การได้เห็นแนวคิดทางคณิตศาสตร์และวิทยาศาสตร์ ถูกนำมาใช้สร้างสิ่งที่เกิดขึ้นจริง เช่น อาคาร ถนน และสะพาน

ผม/หนูต้องการพัฒนาทักษะด้านการคิดวิเคราะห์ การแก้ปัญหา การออกแบบ และการทำงานร่วมกับผู้อื่น เพื่อเตรียมตัวสำหรับการศึกษาต่อในสายวิศวกรรมศาสตร์

Projects & Activities

ผลงานและกิจกรรม

ตัวอย่างผลงานและกิจกรรมที่แสดงถึงความสนใจ ในด้าน STEM การออกแบบ การแก้ปัญหา และวิศวกรรม

PROJECT 01 • STEM

โครงงานสะพานไม้ไอติม

ทดลองออกแบบและสร้างสะพานจากไม้ไอติม เพื่อศึกษาการรับน้ำหนักและความแข็งแรงของโครงสร้าง

เรียนรู้: โครงสร้าง • การแก้ปัญหา • Teamwork

PROJECT 02 • CHALLENGE

STEM Bridge Challenge

กิจกรรมออกแบบสะพานภายใต้ข้อจำกัดด้านวัสดุ และทดสอบประสิทธิภาพของโครงสร้าง

เรียนรู้: Design Thinking • ทดลอง • วิเคราะห์

PROJECT 03 • DESIGN

การออกแบบบ้านใน SketchUp

ฝึกสร้างแบบจำลองบ้าน 3 มิติ และทดลองจัดพื้นที่ใช้สอยอย่างเป็นระบบ

เรียนรู้: 3D Modeling • Design • Spatial Thinking

PROJECT 04 • STRUCTURE

แบบจำลองโครงสร้างอาคาร

ศึกษาส่วนประกอบพื้นฐานของโครงสร้างอาคาร และสร้างแบบจำลองเพื่อทำความเข้าใจการรับแรง

เรียนรู้: Structure • Load • Observation

PROJECT 05 • PHYSICS

โครงงานแรงและการเคลื่อนที่

ทดลองเกี่ยวกับแรง การเคลื่อนที่ และการเปลี่ยนแปลงของวัตถุจากสถานการณ์ต่าง ๆ

เรียนรู้: Physics • Experiment • Analysis

PROJECT 06 • CAMP

ค่ายวิทยาศาสตร์และวิศวกรรม

เข้าร่วมกิจกรรม STEM และเรียนรู้แนวคิด ทางวิทยาศาสตร์และวิศวกรรมผ่านการลงมือปฏิบัติ

เรียนรู้: STEM • Collaboration • Exploration

PROJECT 07 • ROBOTICS

กิจกรรม Robotics / STEM

เรียนรู้พื้นฐานการออกแบบและควบคุมระบบ ผ่านกิจกรรม Robotics และการแก้โจทย์แบบเป็นขั้นตอน

เรียนรู้: Logic • Programming • Teamwork

PROJECT 08 • INVENTION

การประกวดสิ่งประดิษฐ์

พัฒนาแนวคิดสิ่งประดิษฐ์เพื่อแก้ปัญหาใกล้ตัว และนำเสนอแนวคิดต่อเพื่อนและคุณครู

เรียนรู้: Creativity • Presentation • Problem Solving

PROJECT 09 • MATHEMATICS

กิจกรรมคณิตศาสตร์

เข้าร่วมกิจกรรมแก้โจทย์และเกมคณิตศาสตร์ เพื่อฝึกการคิดอย่างมีเหตุผลและเป็นระบบ

เรียนรู้: Logical Thinking • Accuracy • Analysis

PROJECT 10 • VOLUNTEER

กิจกรรมจิตอาสา / พัฒนาชุมชน

ร่วมกิจกรรมพัฒนาพื้นที่และช่วยเหลืองานส่วนรวม เพื่อเรียนรู้การทำงานร่วมกับผู้อื่น

เรียนรู้: Responsibility • Teamwork • Community

Why Civil Engineering?

ทำไมผม/หนูจึงสนใจวิศวกรรมโยธา

เพราะวิศวกรรมโยธาเป็นศาสตร์ที่นำความรู้ มาสร้างสิ่งที่มีประโยชน์ต่อผู้คน และเปิดโอกาสให้เราได้ใช้ทั้งความคิดสร้างสรรค์ คณิตศาสตร์ วิทยาศาสตร์ และการแก้ปัญหา

01

Build

สร้างสิ่งที่เป็นประโยชน์และช่วยพัฒนาคุณภาพชีวิต

02

Solve

ใช้เหตุผลและความรู้เพื่อแก้ปัญหาอย่างเป็นระบบ

03

Design

เปลี่ยนไอเดียให้กลายเป็นแบบจำลองและแนวคิดที่จับต้องได้

04

Impact

สร้างผลงานที่สามารถส่งผลดีต่อผู้คนและสังคม
